## 🚀 Why Redoc Is an Essential Tool

<AnimatedUsageTip
  tip="Redoc is ideal when clarity, audit readiness, and schema depth matter more than request testing."
  emphasis="Perfect for documentation teams, auditors, and stakeholders needing deep insight into schema logic."
/>

<p>Redoc provides a scroll-first, top-down view of your entire API. This is essential when onboarding new developers, reviewing contracts across teams, or inspecting complex interrelations between models. Instead of hiding details inside modals or code blocks, Redoc reveals the structure of every schema using collapsible trees, inline annotations, and rich tooltips.</p>

## 🧱 Schema Clarity: Why Redoc Wins for Modeling

<p>Redoc allows us to model relationships with far more transparency. Consider schemas that define nested relationships, user preferences, configuration options, and sub-resource lists. Redoc collapses them into clean, human-readable diagrams that follow the spec but look like a well-organized UI map.</p>

<SpotlightCode
  title="Nested Schema Example"
  yamlCode={`components:
  schemas:
    User:
      type: object
      required:
        - id
        - email
      properties:
        id:
          type: string
        email:
          type: string
        preferences:
          $ref: '#/components/schemas/Preferences'
    Preferences:
      type: object
      properties:
        notifications:
          type: boolean
        timezone:
          type: string
          default: 'UTC'
        theme:
          enum: ['light', 'dark']`}
  jsonCode={`{
  "components": {
    "schemas": {
      "User": {
        "type": "object",
        "required": ["id", "email"],
        "properties": {
          "id": { "type": "string" },
          "email": { "type": "string" },
          "preferences": { "$ref": "#/components/schemas/Preferences" }
        }
      },
      "Preferences": {
        "type": "object",
        "properties": {
          "notifications": { "type": "boolean" },
          "timezone": { "type": "string", "default": "UTC" },
          "theme": { "enum": ["light", "dark"] }
        }
      }
    }
  }
}`}
/>

<p><strong>Figure 2.</strong> This schema shows the strength of Redoc’s inline collapsing, hover highlighting, and hierarchy tracking. You can spot constraints, types, defaults, and links all at once.</p>

## 💡 Real-World Use Cases for Redoc

<p>Let’s say your API powers a fintech platform. You must document payment payloads, nested currency conversions, and fraud prevention layers. Every object is validated by external systems and must show exact constraints. Redoc is how you build trust, not just functionality.</p>

### 🛠️ Redoc Implementation in React

<p>You can embed Redoc using several methods: CLI builds, HTML via CDN, or the React version. We use the latter because it enables custom themes, scroll behavior, and selective panel visibility for a cleaner UX.</p>

<SpotlightCode
  title="Redoc Embed via React"
  yamlCode={`import { RedocStandalone } from 'redoc';

<RedocStandalone
  specUrl="/fake-spec.yaml"
  options={{
    hideDownloadButton: true,
    hideHostname: true,
    disableSearch: true,
    scrollYOffset: 60,
    nativeScrollbars: true,
    theme: {
      layout: {
        showSidePanel: false,
        showRightPanel: false,
      },
    },
  }}
/>`}
  jsonCode={`{
  "specUrl": "/fake-spec.yaml",
  "options": {
    "hideDownloadButton": true,
    "hideHostname": true,
    "disableSearch": true,
    "scrollYOffset": 60,
    "nativeScrollbars": true,
    "theme": {
      "layout": {
        "showSidePanel": false,
        "showRightPanel": false
      }
    }
  }
}`}
/>

<p><strong>Figure 4.</strong> Here we see Redoc embedded via <code>RedocStandalone</code>, customized for smooth scroll, readability, and theme compatibility. All visual components adapt to your light/dark mode.</p>
